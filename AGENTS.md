# lkr_ai_tool Agent Rules

This repository stores reusable workflows, skills, templates, and tool choices.
It is not the user's private project data.

## Scope

- Keep content project-neutral unless a file is explicitly marked as a profile or
  example.
- Do not commit private documents, reports, raw datasets, credentials, or large
  generated artifacts.
- Prefer editable source artifacts over flattened exports.

## Editing Rules

- Keep docs concise and action-oriented.
- Use ASCII unless a file has a clear need for non-ASCII text.
- When adding a skill, include only the required `SKILL.md` and optional
  resources that directly support the workflow.
- Do not add bulky installation guides inside skill folders; put general notes in
  `docs/`.

## Verification

- After changing scripts, run at least a syntax or smoke check when feasible.
- After changing templates or skills, inspect the repository tree and make sure
  names are generic and portable.
- Keep source links in `docs/tool_catalog.md` when recommending external tools.
