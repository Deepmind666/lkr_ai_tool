# Project Memory Handoff

Use this skill at the end of any substantial session or before moving work to a
different computer, GPT, or human collaborator.

## Record

- project name,
- machine role,
- exact source paths,
- exact output paths,
- changed files,
- commands/tools used,
- checks passed,
- checks skipped and why,
- unresolved risks,
- next concrete task.

## Style

Write facts, not chat summaries. Another agent should be able to continue
without guessing.

## Memory Categories

- Stable project rules.
- User preferences.
- File safety rules.
- Figure and PPT source locations.
- Code repo commit and branch.
- Experiment data locations.
- Known failure cases.
